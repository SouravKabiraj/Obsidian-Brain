# Advantage of Document Model
1) Easily scalable 
2) Handle high data load
3) Handle very high write throughput
4) Provide special query supports, i.e.
   - graph operation (Neo4j)
   - Time-Series Operations (Prometheus)
   - Geospatial Operations (Mongo DB)
   - Full-Text & Semantic Search (ElasticSearch)
   - JSON-native queries (MongoDB)
   - OLAP Operations (Snowflake)
5) Schema Flexibility (Schema on read)
